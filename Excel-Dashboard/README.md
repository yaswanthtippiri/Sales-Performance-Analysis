# Excel Sales Performance Dashboard

This folder contains the Excel workbook developed for the Sales Performance Analysis project.

### Workbook Contents
- **Dashboard:** Overall sales performance visualization.
- **Products:** Product-wise sales analysis.
- **Sales Mans:** Salesperson-wise performance analysis.
- **Master Data:** Raw sales data.
- **Pivot Table:** Summarized sales insights.
- **About:** Project information.

### Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Dashboards
